    Fix invoices.contract_id NOT NULL blocking unmatched invoices

    (client has no active contract, or no rate matches the memo) can be saved

    does not reliably drop NOT NULL in Postgres - so approving such a memo failed
    with a not-null constraint violation.

    existing sync-db.js pattern so teammates can reproduce the fix.
