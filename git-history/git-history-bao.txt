    feat(quotations): add delete action to intake/bookings tables
    
    DELETE /api/intake/:id (rejected submissions only) and DELETE
    /api/bookings/:id (invoiced bookings only) let the Quotations
    Specialist clear resolved rows out of the two list tables. Deleting a
    booking transactionally cleans up its Service Memo, Invoice, invoice
    line items, and job milestones, but deliberately leaves XeroSyncLog
    rows in place as the last local trace that a sync happened.
    
    Adds a shared ConfirmDialog component so these destructive actions are
    confirmed in-app instead of via a browser window.confirm() popup.
    
    Also fixes a color mismatch between the Bookings stat cards and their
    own status badges, makes filter pills/stat cards tint to their status
    color when active on both tables, removes the row hover color change,
    and makes whole rows (not just the Review button) open the detail
    modal on click.
    
    Fills in test coverage for backend/tests/zheng-bao/ and
    frontend/tests/zheng-bao/, which previously had no test files.
